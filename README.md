# Stefano Cacciatore, MD

Static website deployed with GitHub Pages at https://stefanocacciatore.org/.

## Structure

- `index.html`: Home.
- `curriculum/index.html`: Education, appointments, editorial activity and affiliations.
- `publications/index.html`: Publications grouped by research area.
- `news/index.html`: News archive and individual article directories.
- `longevity-brief/index.html`: Longevity Brief issues.
- `assets/`: Optimized images, icons and social sharing previews.
- `style.css`, `script.js`: Shared presentation and navigation.
- `CNAME`, `robots.txt`, `sitemap.xml`: Custom domain and indexing configuration.

The site does not require a build step. Publish the contents of this directory at the repository root.
